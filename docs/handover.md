- [x] Login/logout Admin, CRUD sản phẩm, ảnh, responsive, tìm kiếm/sắp xếp số, export Web.
- [x] Rules giới hạn UID và schema, bộ kiểm thử tự động.
- [x] Hướng dẫn cài đặt, chạy ba nền tảng và kịch bản video.
- [x] Firebase options thật do FlutterFire sinh đủ ba app.
- [x] Rules đã biên dịch và deploy lên project thật.
- [ ] Kiểm thử truy cập Admin/UID khác trên project thật.

- [ ] Báo cáo Word/PDF hoàn chỉnh với minh chứng thực tế.
- [ ] GitHub public đã push; link repository kiểm tra được.
